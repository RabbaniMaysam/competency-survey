Competency self-assessment: privacy

This page is a course tool. Students of a class rate their own career competencies at the start and at the end of the semester.

Sign-in. The page uses Google sign-in only to confirm the email address of the person using it. It reads the email address and the verified status from the sign-in token, nothing else. It has no access to Google accounts, mail, files, or contacts.

Data kept. For each class: the roster the instructor uploads (first name, last name, email), each student's answers with the time of the last change and of submission, and an activity log of submissions and instructor actions with their time. The data is stored on Cloudflare and is visible only to the instructor. Students see only their own answers.

Retention. The instructor deletes a class's data when it is no longer needed.

Sharing. The data is not shared with anyone and is used only for the course.

Contact. Questions go to the course instructor.
